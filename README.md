# Financial Market Regime Modelling using Hidden Markov Models (HMM)

A full-stack quantitative financial application developed for an AI and Machine Learning university assignment (Master's in Data Science).

The application uses historical financial market returns as continuous observations to infer latent/unobserved market regimes (**Bull**, **Stable**, and **Bear**) using Gaussian Hidden Markov Models.

## 3. Data Preprocessing & Log-Return Methodology (Phase 2)

Raw market price series $P_t$ are non-stationary (exhibiting stochastic trends and unit roots). Financial econometric models require transformation into stationary, continuously compounded returns.

### A. Preprocessing Pipeline Steps
1. **Schema Validation**: Detects and standardizes required columns (`Date` and `Close`) using case-insensitive matching (`date`, `datetime`, `timestamp`; `close`, `adj close`, `price`).
2. **Missing & Invalid Value Handling**:
   - Blank or unparseable dates are removed.
   - Non-numeric prices or strings are stripped.
   - Observations with missing attributes are dropped transparently with documented warnings in the API payload. The pipeline never fabricates synthetic financial prices to maintain statistical validity.
3. **Price Sanity Check**: Ensures closing prices are strictly positive ($P_t > 0$), as negative or zero prices are economically invalid and make $\ln(P_t)$ mathematically undefined.
4. **Duplicate Resolution**:
   - If multiple records exist for the same date, the system retains the **latest observation** (`keep='last'`). In quantitative market feeds, subsequent records for a single date represent revised post-market settlement prices.
   - A warning listing the affected dates and count is recorded in the response.
5. **Chronological Ordering**: The cleaned records are sorted in strictly ascending chronological order using a stable sort algorithm.
6. **Sample Size Feasibility**: A minimum threshold of 30 valid observations is enforced to ensure sufficient degrees of freedom when estimating 3-state HMM parameters in Phase 3.

### B. Mathematical Return Calculation
Logarithmic returns are calculated as:
$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1})$$

- **First Observation ($t=0$)**: Since $P_{-1}$ does not exist, the initial observation has `log_return = null`.
- **Return Vector for HMM**: An array of $T-1$ continuous returns is generated:
  $$\mathbf{r} = [r_1, r_2, \dots, r_{T-1}] \in \mathbb{R}^{T-1}$$
  ready for Gaussian emission fitting via the Baum-Welch algorithm.

## 4. Hidden Markov Model (HMM) Methodology (Phase 3)

### A. What is a Hidden Markov Model?
A **Hidden Markov Model (HMM)** is a doubly stochastic probabilistic graphical model designed for sequential time series data. It posits that the observable time series is generated by an underlying discrete stochastic process whose true state sequence is **unobserved (hidden)**. The system satisfies the first-order Markov property: the future latent state depends only on the current state, and the observable distribution at time $t$ depends solely on the latent state at time $t$.

### B. Why HMMs for Financial Market Regime Modelling?
Financial time series exhibit well-documented empirical "stylized facts" (Mandelbrot 1963, Cont 2001) that invalidate static linear models:
1. **Volatility Clustering**: Large price fluctuations are followed by large fluctuations, and quiet periods by quiet periods.
2. **Structural Breaks & Asymmetry**: Equity markets alternate between prolonged upward trends with low volatility (bull regimes) and sudden, violent downturns with elevated variance (bear regimes).
3. **Regime Switching**: Following James Hamilton's seminal work (Hamilton 1989), market dynamics are modelled not as a single global Gaussian distribution, but as switching between unobserved economic regimes with persistent transition probabilities.

### C. Mathematical Formulation & Notation

#### 1. Observed Variables
The observations are the continuous daily log returns:
$$\mathbf{Y}_{1:T} = (y_1, y_2, \dots, y_T), \quad \text{where } y_t = r_t \in \mathbb{R}$$

#### 2. Hidden State Space
The unobserved market regime at time $t$ is denoted by $S_t \in \{1, 2, \dots, K\}$, with $K = 3$ states corresponding to the canonical economic states:
$$S_t \in \{\text{Bear}, \text{Stable}, \text{Bull}\}$$

#### 3. Initial State Distribution
The initial regime probability vector $\boldsymbol{\pi} = (\pi_1, \pi_2, \pi_3)^\top$:
$$\pi_i = P(S_1 = i), \quad \sum_{i=1}^3 \pi_i = 1, \quad \pi_i \ge 0$$

#### 4. Transition Probability Matrix
The transition dynamics between hidden states are governed by a row-stochastic matrix $\mathbf{A} = (a_{ij}) \in \mathbb{R}^{3 \times 3}$:
$$a_{ij} = P(S_t = j \mid S_{t-1} = i), \quad \sum_{j=1}^3 a_{ij} = 1, \quad a_{ij} \ge 0$$
- **Diagonal Elements ($a_{ii}$)**: Measure the **persistence (stickiness)** of regime $i$.
- **Expected Regime Duration**: Under the Geometric holding-time property of Markov chains:
  $$\mathbb{E}[D_i] = \frac{1}{1 - a_{ii}} \text{ trading days}$$

#### 5. Gaussian Emission Distribution
Given state $S_t = k$, the continuous observation $y_t$ is distributed according to a state-conditional normal distribution:
$$b_k(y_t) = P(y_t \mid S_t = k) = \mathcal{N}(y_t \mid \mu_k, \sigma_k^2) = \frac{1}{\sqrt{2\pi\sigma_k^2}} \exp\left( -\frac{(y_t - \mu_k)^2}{2\sigma_k^2} \right)$$
where:
- $\mu_k$: Expected daily mean return under regime $k$.
- $\sigma_k$: Daily return volatility (standard deviation) under regime $k$.

### D. Parameter Estimation via Baum-Welch (Expectation-Maximization)
The parameter set $\theta = (\boldsymbol{\pi}, \mathbf{A}, \boldsymbol{\mu}, \boldsymbol{\Sigma})$ is estimated to maximize the incomplete-data log-likelihood:
$$\hat{\theta} = \arg\max_\theta \ln P(\mathbf{Y}_{1:T} \mid \theta) = \arg\max_\theta \ln \sum_{\mathbf{S}} P(\mathbf{Y}_{1:T}, \mathbf{S} \mid \theta)$$
This is solved iteratively via the **Baum-Welch algorithm**:
- **E-step**: Compute forward variables $\alpha_t(i) = P(Y_{1:t}, S_t = i \mid \theta)$ and backward variables $\beta_t(i) = P(Y_{t+1:T} \mid S_t = i, \theta)$.
- **M-step**: Re-estimate transition probabilities $\hat{a}_{ij}$, emission means $\hat{\mu}_k$, and emission variances $\hat{\sigma}_k^2$ by maximizing the expected complete-data log-likelihood.

### E. Inference & Decoding

#### 1. Viterbi Optimal Decoding (Global Most Likely Path)
To determine the single most probable discrete regime sequence across the entire timeline:
$$\mathbf{S}^*_{1:T} = \arg\max_{S_1, \dots, S_T} P(S_1, \dots, S_T \mid \mathbf{Y}_{1:T}, \hat{\theta})$$
Computed dynamically in $O(K^2 T)$ time using dynamic programming:
$$v_t(j) = \max_{i} \left( v_{t-1}(i) \cdot a_{ij} \right) \cdot b_j(y_t)$$

#### 2. Posterior State Probabilities (Smoothed Probabilities)
The marginal posterior probability of being in state $k$ at time $t$ given the complete observation history $\mathbf{Y}_{1:T}$:
$$\gamma_t(k) = P(S_t = k \mid \mathbf{Y}_{1:T}, \hat{\theta}) = \frac{\alpha_t(k)\beta_t(k)}{\sum_{j=1}^K \alpha_t(j)\beta_t(j)}$$
These probabilities quantify model confidence and form the continuous probability streams displayed on the dashboard.

### F. Deterministic Regime Labeling & Label Switching
Hidden Markov Models are strictly **unsupervised**. The Expectation-Maximization algorithm assigns arbitrary numerical indices $\{0, 1, 2\}$ to components, leading to the classical **label switching problem** (e.g., State 0 might represent a bull market in one run, but a bear market in another).

To ensure deterministic, academically rigorous, and interpretable outputs:
1. Following model convergence, the estimated emission means are evaluated:
   $$\boldsymbol{\mu} = (\mu_0, \mu_1, \mu_2)$$
2. States are deterministically mapped by sorting in ascending order of estimated mean return:
   $$\mu_{\text{sorted}[0]} < \mu_{\text{sorted}[1]} < \mu_{\text{sorted}[2]}$$
   - **Bear Regime**: State with the **lowest** mean return ($\mu < 0$, typically high volatility).
   - **Stable Regime**: State with the **median** mean return ($\mu \approx 0$, lowest volatility).
   - **Bull Regime**: State with the **highest** mean return ($\mu > 0$, moderate volatility).
3. The original unsupervised HMM state IDs are preserved internally (`regime_mapping`), allowing complete traceability from raw algorithmic output to economic regimes.

> [!IMPORTANT]
> **Academic Disclaimer**: The Hidden Markov Model is an inferential econometric tool designed to diagnose and characterize historical and current market states. It models latent statistical properties (conditional distribution shifts and volatility clustering). It does **not** guarantee future market returns or predict future prices. Financial markets are non-stationary and subject to exogenous macroeconomic shocks that lie outside the scope of closed Markovian systems.
